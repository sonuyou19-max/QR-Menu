# Demo restaurant assets

Brasserie Lindehof (`/m/demo`) is a made-up restaurant with no members, so its images can't be
uploaded through the app.

- `lindehof-logo.html`: the logo source (SVG, Playfair Display, the demo's burgundy `#8c1c13`).
  It was rendered to `app/public/demo/lindehof-logo.png` (512 × 512, transparent) with Playwright.
- `app/public/demo/lindehof-cover.jpg`: the cover photo (4:3, AI-generated by the owner).
- `app/public/demo/dishes/`: dish photos (AI-generated by the owner), each as a 1200 px photo and
  a 400 px `_thumb`, like the app makes on upload.
- The app serves the files from `app/public/demo/`. The edge function `seed-demo-branding` copies
  them from `https://app.brisolo.be/demo/` into storage under the demo's folder (logo and cover
  into `branding`, dish photos into `dish-images`). To add a file: put it in `app/public/demo/`,
  add it to `FILES` in the function, push, wait for the app to deploy, redeploy and call the
  function, then set the path (`logo_path`, `theme.cover_path`, `image_path` /
  `image_thumb_path`) in a migration.
